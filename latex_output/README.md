# RASSDroid SAT-OTAA Analysis - LaTeX Output

This directory contains LaTeX-formatted tables, figures, and analysis for the RASSDroid SAT-OTAA experimental results.

## Files Overview

### Main Analysis Documents
- `complete_analysis.tex` - Full comprehensive analysis document
- `enhanced_analysis.tex` - Enhanced version with advanced formatting and colors

### Paper-Ready Components
- `paper_main_table.tex` - Main results table for paper (recommended)
- `detailed_stats_table.tex` - Detailed statistics table for appendix
- `paper_section.tex` - Complete section ready for paper inclusion
- `tikz_charts.tex` - TikZ/PGFPlots charts (requires pgfplots package)

### Legacy Files
- `summary_table.tex` - Basic summary table
- `raw_stats_table.tex` - Raw statistics table

### Generated Figures
- `performance_comparison.pdf` - Comprehensive performance comparison chart
- `trend_analysis.pdf` - Performance trend analysis
- `*.png` versions also available

## Usage Instructions

### For Academic Papers

1. **Main Results Table**: Use `paper_main_table.tex`
   ```latex
   \input{paper_main_table.tex}
   ```

2. **Complete Section**: Include `paper_section.tex` in your paper
   ```latex
   \input{paper_section.tex}
   ```

3. **Figures**: Include the PDF figures
   ```latex
   \begin{figure}[htbp]
   \centering
   \includegraphics[width=0.8\textwidth]{trend_analysis.pdf}
   \caption{Performance trends}
   \end{figure}
   ```

### Required LaTeX Packages

For basic usage:
```latex
\usepackage{booktabs}
\usepackage{multirow}
\usepackage{graphicx}
```

For enhanced formatting:
```latex
\usepackage{xcolor}
\usepackage{colortbl}
\usepackage{siunitx}
```

For TikZ charts:
```latex
\usepackage{pgfplots}
\usepackage{tikz}
\pgfplotsset{compat=1.17}
```

## Compilation

### Standard Compilation
```bash
pdflatex your_paper.tex
```

### For TikZ Charts
```bash
pdflatex tikz_charts.tex  # Generates standalone chart
```

### For Complete Analysis
```bash
pdflatex enhanced_analysis.tex
```

## Key Results Summary

The analysis covers three RASSDroid versions with SAT-OTAA:
- **06/13**: Baseline performance
- **07/09**: Initial improvements  
- **07/29**: Best overall performance

### Highlights
- Task completion: 22.2% → 23.0% (+0.8pp)
- Page F1-score: 0.432 → 0.458 (+6.0%)
- Assertion F1-score: 0.179 → 0.211 (+17.9%)

## Customization

To modify table formatting, edit the respective `.tex` files. The tables use:
- `\textbf{}` for bold text (best values)
- `\textit{}` for italic text (improvements)
- `booktabs` package for professional table formatting
